functionality_tester.py will walk you through using the not only the latency predictors but also building and registering a custom predictor for an android device.

Prerequisites:
  - Python 3.9
  - create a virtual environment for the builder
  - activate virtual environment
  - install requirements from builder_requirements.txt
  - install nn-meter in tool folder: run pip install .


How to run the CLI
- First, run the file functionality_tester.py
- then when prompted, enter the word "new."
- then you can follow the menu on what options you want to select
